# Hero Section 05 | Sky Blue Business

Live Demo: [https://9940-pg.github.io/Hero-section05/] .

A modern, responsive hero section built with **HTML**, **Tailwind CSS**, and **JavaScript**. This section is designed for a business website, featuring a bold heading, descriptive paragraph, animated CTA buttons, decorative floating circles, and dark mode support.

---

## Features

- **Responsive Design:** Adapts seamlessly from mobile to desktop.
- **Dark Mode:** Toggle between light and dark themes.
- **Animated Elements:** 
  - Fade-in-up effect for heading and paragraph.
  - Floating decorative circles for a dynamic look.
  - Smooth button hover and arrow animations.
- **CTA Buttons:** Styled with borders, gradient backgrounds, and interactive hover effects.
- **Mobile Menu Drawer:** Hamburger menu for smaller screens.
- **Modern Fonts & Styling:** Uses a clean, professional font with stylish gradient backgrounds.

---

## Technologies Used

- **HTML5**
- **Tailwind CSS**
- **JavaScript**
- **Google Fonts** (`Poppins`)
